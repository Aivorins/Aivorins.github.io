HOW IT WORKS

A Quick Panel, then the full view.

Insight starts as a compact, frameless panel that shows you the essentials at a glance — CPU, RAM, disk, and temperature. Click to expand into a full dashboard with detailed performance data, app management, startup controls, and history charts. One background thread collects everything; one state drives every view.

01 · SAMPLE
One-Second Metrics Loop
A single background thread refreshes CPU, RAM, disk activity, and temperature every second. The Overview snapshot is captured before the process refresh so the headline numbers stay consistent across every page in the dashboard.
02 · EVALUATE
Sustained-Duration Insights
The insight engine looks at your system state over time, not just a single snapshot. It flags conditions that persist — high RAM for 2 minutes, sustained CPU load, low disk space — so you only see warnings that actually matter, not momentary spikes.
03 · ACT
Manage Without Leaving
Close background apps you don't need, toggle startup entries, clear temp files with an allowlist-only cleanup engine — all from inside the dashboard. Every action is user-initiated, double-confirmed, and scoped to safe targets.

FEATURES

Everything you need.
Nothing you don't.

Built as a Tauri 2 app with a Rust backend and a plain HTML/CSS/JS frontend — no bundler, no framework, no dependencies. Designed to stay light even on older hardware.

Quick Panel
A tiny, frameless 300x210 panel that sits on your desktop showing CPU, RAM, disk, and temperature at a glance. Drag it anywhere, expand it when you need more detail.
Performance Dashboard
Full view with per-core CPU bars, memory breakdown, disk activity, CPU temperature, and a process explorer — all updating in real time without lagging the interface.
Smart Insights
Condition-based alerts that only fire when something is sustained — not momentary spikes. High RAM for 2 minutes, CPU load held for 60 seconds, disk running low. Warnings with context and recommended actions.
App Manager
See all running apps grouped by name with their memory and CPU usage. Close any app you don't need with a two-step confirmation — protected system processes can't be touched.
Startup Manager
View and toggle every app that starts with Windows — directly from the registry. Disable or re-enable entries without deleting them, so nothing is ever lost.
Safe Cleanup
Allowlist-only temp file cleaning — logs, crash dumps, browser caches. No discovery, no guessing. Every deletable item is reviewed, path-validated, and protected against symlink escapes.
Local-First, Always
No cloud sync, no remote data, no telemetry. Every metric, every setting, every byte stays on your machine. Built on Tauri with strict process isolation.
History & Charts
Tiered history with four resolution levels — from live to long-term — rendered as pure SVG charts. See how your system performs over minutes, hours, and days.
